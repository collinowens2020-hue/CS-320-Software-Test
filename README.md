# CS-320-Software-Test
School projects showcasing software testing, automation, and quality assurance.


Building reliable and secure software starts with writing clean, modular code and checking it continuously with thorough unit tests to catch bugs before they cause problems. Before writing a single line of code, I make sure to carefully break down user requirements into clear, logical steps so the program does exactly what the user expects. When designing the application, I focus on creating independent components that handle their own tasks without interfering with the rest of the system. This structured approach ensures the software works correctly, keeps data safe, and stays simple enough for any developer to update down the road.
